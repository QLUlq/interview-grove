# 面向 · 本机使用版 1.0.0

完成日期：2026-11-19。此版本用于本机练习和演示，核心文字流程完成；不包含公网部署或跨设备同步。

## 交付范围

- 求职练习：上传项目文件夹或简历图片，按材料安排问题，支持草稿、继续练习和提前结束。
- 项目理解：从功能、流程到模块协作和验证，展示实际读取范围与代码依据，不将教程复现描述成独立原创。
- 考研复试：按报考专业、408、信号与系统或自定义范围安排练习。
- 复盘与重练：整轮摘要、逐题分析与润色、原答分支、单题重答对照；求职和复试记录分开展示。
- 复试刷题：历史题重练、按范围生成口头题或选择题、错题与待复习、自评和历次作答保留。
- 数据保存：本机账号隔离、访客空间独立、单条删除确认、分支保留和记录下载备份。
- 模型路由：明确的单模型免费额度耗尽时切换已配置候选，展示实际模型；依赖服务商“用完即停”设置。
- 辅助语音输入：Windows 本机离线识别优先，文字追加到草稿，核对后手动提交。识别失败可继续键盘输入或使用 Win + H。

## 使用与备份

建议使用 Node.js 22.13+ 的22.x版本，或更新的LTS版本，以便直接使用内置 SQLite。在项目目录运行 `npm start`，访问 http://localhost:3001 。AI 配置按 [README](../README.md) 设置在本机 `.env`，更改配置后重启服务。

账号数据保存在 `data/interviews.sqlite`；访客记录在当前浏览器、当前地址的 localStorage 中。可在应用内下载记录备份；JSON 下载用于留存，当前不提供通用 JSON 恢复入口。完整迁移本机账号数据前应停止服务，再复制整个 `data` 目录，避免遗漏 SQLite 事务文件。保管好本机 `.env`，分享源码时排除 `.env`、`data` 和个人测试产物。

## 已知限制

- 离线语音引擎对技术词和普通句子均可能出现明显误识别，当前不宜依赖其完整转写面试回答。音量正常也可能识别错误。浏览器语音备用模式还可能受网络服务限制。
- AI 题目、参考答案和润色可能有误，结构校验不等于内容正确；没有完成全面面试质量评测，不把练习完成或自评当作已经掌握。
- 项目最多读取80个文件、约11万字符，并非全仓库理解；不编造测试结果、排错经历或原创贡献。
- 不支持实时免费余额查询、模型训练、密码找回、跨设备云同步或生产环境部署。
